## 1. 路线A：图生视频（★强烈推荐，人物绝不会跑偏）

**原理**：首帧图里人物长什么样，生成的视频就保持什么样——根本不需要担心"人物形象"。

**操作三步**：
1. 打开即梦/可灵 → 找到 **【图生视频】**（即梦叫"图片生成视频"，可灵叫"图片转视频"）
2. 上传下表对应镜号的**首帧图** → 把**动效提示词**整条复制粘贴进去 → 生成（每次生成会消耗额度，建议每镜抽 2~4 次选最好的）
3. 全部镜头导出 1080p → 导入剪映 → 按镜号顺序排列、按镜长裁剪 → **关掉视频自带声音** → 拖入 `build/premix.wav` → 导出成片 ✅

## 2. 路线B：纯文生视频 + 角色锁定（想重画画面时用）

适合不满意某镜构图、想完全重新生成的情况。**人物一致性**靠两种方法：

**方法1（推荐）：上传角色参考图**。把 `characters/` 里的形象图传给平台的参考功能：
- 即梦AI：生成页选 **"智能参考"/"主体参考"**，上传 `ref_bai.png` 等
- 可灵AI：**"形象锁定"/"角色扮演"** 功能
- Vidu：**"参考生视频"**（支持多主体）
- Runway：**Character Reference / Actors**

**方法2：提示词锚点**。每条提示词开头固定粘贴同一段角色描述（描述不变，长相才不变）：

> 白娘子锚点：`一位绝美的中国年轻古典美人，纯白飘逸汉服银线绣纹，乌黑长直发配银色发簪，气质温婉， photorealistic CG, 宋代古风`

## 3. 台词口型怎么办（可选）

即梦/可灵的口型同步能力有限，三个方案：
1. **不追求口型**（推荐）：镜头多用特写/半身+手部表演，观众看字幕听声音即可（本片字幕方案就是这么设计的）
2. **剪映"对口型"**：生成好视频后，用剪映的数字人/对口型功能让角色对上台词
3. 即梦"数字人"功能：适合人物正面说话的镜头（镜2/3/6/10/11/13）

## 4. 最后拼接（剪映，10分钟）

1. 新建 1920×1080 项目 → 按 `README.md` 时间轴顺序拖入 14 个镜头视频
2. 每镜裁剪到表中标 注的镜长（3s/2s/4s…）
3. 全选视频 → 右键"静音"（去掉AI生成的杂音）
4. 拖入 `build/premix.wav` 到音轨（52s，含全部台词音效BGM）——注意它前 39s 对应正片，39s 后是片尾板音乐；片尾板画面可用镜14定格+渐黑
5. 导出 1080p/30fps ✅ 完成

> 或者：不用重做，**本项目的 `output/白蛇酒变_v2.mp4` 已是可直接投放的成片**；AI 视频版是画质/口型升级选项。
