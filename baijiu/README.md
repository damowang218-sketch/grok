## 制作管线（全自动化，可一键重渲）

```bash
python3 build.py      # 替身图→音效/BGM合成→混音→14镜动效渲染→片尾→拼接 (v1)
python3 fix_audio.py  # 台词变速/响度归一/闪避→BGM52s重排→混音→重拼 (v2，当前版本)
```

- **画面**：AI 生成分镜关键帧（`assets/`）+ ffmpeg zoompan 运镜（缓推/俯拍推进/天旋地转 sway/跟拍 shake）
- **字幕**：PyMuPDF 内嵌中文字体渲染 PNG（`ui/`）叠加淡入淡出，严格只出现脚本 4 处
- **配音**：4 个音色（许仙/白娘子/小青/旁白），静音压缩+atempo 变速+响度归一+BGM 闪避
- **音效/BGM**：numpy 程序化合成（`audio/sfx/` 26 个：杯嗒/吞咽/脚步/回音喊声/轰鸣/天旋地转/噗/变身嗡/蝉鸣/叮/问号/乌鸦/鼓点/啪…；BGM 三段式：箫声→紧张急停→轻快鼓点→片尾暖垫）
